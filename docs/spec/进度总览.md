## 可选优化（不阻塞 MVP）

| 事项 | 影响面 | 说明 |
|------|--------|------|
| logout token 黑名单 | 安全性 | 当前 logout 仅删除前端 token |
| LLM_API_KEY 启动校验 | 部署体验 | 后端启动时不报错，第一次 AI 调用才抛 500 |
| notes 全文搜索 | 性能 | 当前 LIKE，大数据量可换 FTS |
| LLM 响应缓存 | 成本 | 相同请求重复调用 LLM |
