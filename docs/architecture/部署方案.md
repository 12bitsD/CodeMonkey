# ConceptTree 部署方案

## 读者确认
- 核心读者：希望将 ConceptTree 部署上线的开发者
- 已具备背景：本地开发完成，了解基本的前后端分离架构
- 最关心：如何快速将项目部署到生产环境

## 问题定义
需要将一个 React + FastAPI 的全栈项目部署到线上环境，支持真实用户使用。

## 核心结论

1. **推荐架构**：前端 Vercel（静态托管）+ 后端 Docker（容器化）+ Supabase（PostgreSQL 数据库）
2. **部署难度**：中等，需要配置多个平台但流程清晰
3. **预计时间**：首次部署约 30 分钟，后续自动化

## 第一步：配置数据库（Supabase）

### 1.1 创建 Supabase 项目

1. 访问 [supabase.com](https://supabase.com) 并登录
2. 点击 **New Project** 创建新项目
3. 填写项目信息：
   - **Name**：`concept-tree-db`（或自定义）
   - **Database Password**：牢记此密码，后续需要用到
   - **Region**：选择离目标用户最近的区域
4. 点击 **Create new project**，等待约 2 分钟创建完成

### 1.2 执行数据库 Schema

1. 进入项目后，点击左侧 **SQL Editor**
2. 复制以下文件内容：
   - `ConceptTree/backend/schema.sql`
3. 粘贴到 SQL Editor 并点击 **Run**
4. 验证表创建成功：左侧 **Table Editor** 应看到 6 张表：
   - `users`
   - `user_profiles`
   - `plans`
   - `nodes`
   - `edges`
   - `learning_sessions`
   - `notes`

### 1.3 获取连接字符串

1. 进入 **Project Settings → Database**
2. 找到 **Connection String** 部分
3. 点击 **URI** 标签
4. 复制连接字符串，格式如下：
   ```
   postgresql://postgres.[PROJECT_REF]:[PASSWORD]@aws-0-[REGION].pooler.supabase.com:6543/postgres
   ```
5. 替换 `[PASSWORD]` 为你设置的数据库密码

## 第二步：部署后端（Docker）

### 推荐平台选择

| 平台 | 优点 | 缺点 |
|------|------|------|
| **Render** | 免费额度、GitHub 集成 | 冷启动较慢 |
| **Railway** | 简单直观、按量付费 | 免费额度有限 |
| **Zeabur** | 中文界面、支持一键部署 | 相对较新 |
| **自建服务器** | 完全控制 | 需要运维 |

本方案以 **Render** 为例。

### 2.1 创建 Render Web Service

1. 登录 [render.com](https://render.com)
2. 点击 **New → Web Service**
3. 连接你的 GitHub 仓库
4. 配置构建设置：

   | 设置项 | 值 |
   |--------|-----|
   | **Root Directory** | `ConceptTree/backend` |
   | **Runtime** | `Docker` |
   | **Branch** | `main` |
   | **Instance Type** | `Free`（测试用）或 `Starter`（生产用）|

5. 点击 **Create Web Service**

### 2.2 配置环境变量

在 Render 控制台的环境变量部分添加：

```env
# 必需
DATABASE_URL=postgresql://postgres.xxx:password@host:6543/postgres
JWT_SECRET_KEY=your-super-secret-key-min-32-chars

# CORS（部署后替换为实际域名）
CORS_ORIGINS=https://your-frontend.vercel.app,http://localhost:3000

# AI 服务（Xiaomi MiMo Token Plan China）
LLM_PROVIDER=mimo_token_plan_cn
LLM_API_KEY=tp-your-mimo-token-plan-cn-api-key
LLM_BASE_URL=https://token-plan-cn.xiaomimimo.com/v1
LLM_MODEL=mimo-v2.5-pro
```

### 2.3 获取后端 URL

部署成功后，Render 会提供公共 URL，格式如：
```
https://concept-tree-api.onrender.com
```

记录此 URL，后续配置前端时需要用到。

## 第三步：部署前端（Vercel）

### 3.1 创建 Vercel 项目

1. 登录 [vercel.com](https://vercel.com)
2. 点击 **Add New → Project**
3. 导入你的 GitHub 仓库
4. 配置项目：

   | 设置项 | 值 |
   |--------|-----|
   | **Framework Preset** | `Vite` |
   | **Root Directory** | `ConceptTree/frontend` |
   | **Build Command** | `npm run build` |
   | **Output Directory** | `dist` |

### 3.2 配置环境变量

在 Vercel 的 Environment Variables 添加：

```env
VITE_API_BASE_URL=https://concept-tree-api.onrender.com
```

> **注意**：`VITE_` 前缀是 Vite 的约定，用于客户端可访问的环境变量。

### 3.3 部署

1. 点击 **Deploy**
2. 等待构建完成（约 2-3 分钟）
3. 获得生产环境 URL，如：
   ```
   https://concept-tree-frontend.vercel.app
   ```

## 第四步：验证部署

### 4.1 后端健康检查

访问后端 API 文档：
```
https://concept-tree-api.onrender.com/docs
```

尝试调用 `/health` 端点：
```
https://concept-tree-api.onrender.com/health
```

应返回：
```json
{"status": "ok"}
```

### 4.2 前端功能测试

1. 访问前端 URL
2. 尝试注册新用户
3. 尝试创建学习计划
4. 验证 AI 图谱生成功能

### 4.3 CORS 问题排查

如果前端调用后端 API 时出现跨域错误：

1. 检查后端 `CORS_ORIGINS` 环境变量是否包含前端域名
2. 格式应为：`https://your-frontend.vercel.app`（无尾斜杠）
3. 修改后需重启后端服务

## 自动化部署（可选）

### GitHub Actions 持续部署

在 `.github/workflows/deploy.yml` 创建：

```yaml
name: Deploy

on:
  push:
    branches: [main]

jobs:
  deploy-backend:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Deploy to Render
        run: |
          curl -X POST https://api.render.com/v1/services/${{ secrets.RENDER_SERVICE_ID }}/deploys \
            -H "Authorization: Bearer ${{ secrets.RENDER_API_KEY }}"

  deploy-frontend:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Deploy to Vercel
        run: npx vercel --prod --token=${{ secrets.VERCEL_TOKEN }}
```

### 需要的 Secrets

| Secret | 获取位置 |
|--------|----------|
| `RENDER_SERVICE_ID` | Render Dashboard → Service → ID |
| `RENDER_API_KEY` | Render Account Settings → API Keys |
| `VERCEL_TOKEN` | Vercel Settings → Tokens |

## 故障排查

### 后端常见问题

| 问题 | 解决方案 |
|------|----------|
| 500 Internal Server Error | 检查 `DATABASE_URL` 是否正确 |
| CORS 错误 | 确认 `CORS_ORIGINS` 包含前端域名 |
| AI 服务调用失败 | 检查 `LLM_API_KEY` 是否有效 |
| 连接数据库超时 | Render 免费版有冷启动延迟，等待 30 秒重试 |

### 前端常见问题

| 问题 | 解决方案 |
|------|----------|
| API 请求 404 | 确认 `VITE_API_BASE_URL` 无尾斜杠 |
| 构建失败 | 检查 `package.json` 依赖是否完整 |
| 样式异常 | 确认 Tailwind 配置正确 |

### 数据库连接问题

```bash
# 本地测试数据库连接
psql $DATABASE_URL -c "SELECT 1"
```
