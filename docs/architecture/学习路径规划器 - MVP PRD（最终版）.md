## 学习路径规划器 - MVP PRD（最终版）

------

### 产品定义

输入学习目标，生成知识依赖图谱，精确到公式级别，引导用户按依赖顺序学习。

------

### 核心概念

**节点状态（3种）：**

| 状态   | 含义     | 视觉              |
| ------ | -------- | ----------------- |
| 未学习 | 还没学   | 灰色 + ○          |
| 已学习 | 学完了   | 绿色填充 + ✓      |
| 不需要 | 用户跳过 | 半透明 + 虚线 + − |

所有节点均可直接操作，无锁定机制。

**用户画像系统：**

画像来源：

-   学习过程中积累（完成的知识点）
-   用户每次输入时提取并更新
-   Agent自动分析生成

画像内容：

-   基础字段：职业/身份、教育背景、编程基础、数学基础
-   能力标签：平铺的自由描述标签
-   已掌握知识点（从学习记录自动汇总）

画像用途：

-   生成图谱时自动标记已掌握的前置为"不需要"
-   调整知识点拆解的粒度
-   推荐更匹配的学习资源
-   确保用户始终在学习区

------

### 页面结构

```
页面 1：首页（输入 + 进行中的计划）
页面 2：图谱页
页面 3：我的学习（归档计划 + 画像 + 笔记 + 统计）
```

**画布**

**布局方式：**

-   目标节点在中心，前置知识向外辐射
-   初始视图显示完整图谱（自动缩放到全部可见）
-   用户可拖拽节点调整位置

**节点样式（按缩放级别）：**

缩小时（<50%）：

```
┌─────┐
│ ✓  │  ← 只显示状态图标
└─────┘
```

正常（50%-100%）：

```
┌─────────────┐
│ ✓ 矩阵乘法 │  ← 图标 + 名称
└─────────────┘
```

放大时（>100%）：

```
┌─────────────────┐
│ ✓ 矩阵乘法      │
│ 3个掌握标准     │  ← 显示掌握标准数量
└─────────────────┘
```

**节点状态样式：**

| 状态   | 样式              |
| ------ | ----------------- |
| 未学习 | 灰色 + ○          |
| 已学习 | 绿色填充 + ✓      |
| 不需要 | 半透明 + 虚线 + − |

目标节点：双线边框 + 🎯

**选中节点：**

-   加粗边框 + 阴影光晕
-   相关边高亮，无关边变淡

**边样式：**

-   实线箭头：正常依赖
-   虚线箭头：指向"不需要"节点

**画布交互：**

-   拖拽空白区域：平移画布
-   滚轮/双指：缩放
-   点击节点：显示卡片，节点加粗+光晕，相关边高亮
-   双击节点：快速切换状态（未学习↔已学习）
-   拖拽节点：调整位置
-   点击空白：收起卡片
