# Trae 调试环境配置说明

## 概述

本项目已配置完整的 Trae 调试环境，支持前端和后端的开发、测试和调试。

## 配置文件

### VS Code 配置

- `.vscode/launch.json` - 调试配置
- `.vscode/settings.json` - 编辑器设置
- `.vscode/tasks.json` - 任务配置
- `.vscode/extensions.json` - 推荐扩展

## 调试配置

### 后端调试

#### 1. FastAPI 服务器调试
- **配置名称**: `后端: FastAPI`
- **功能**: 启动 FastAPI 开发服务器（支持热重载）
- **端口**: 8000
- **使用方法**: 按 F5 或选择此配置启动

#### 2. Python 文件调试
- **配置名称**: `后端: 当前 Python 文件`
- **功能**: 调试当前打开的 Python 文件
- **使用方法**: 打开任意 Python 文件，按 F5

#### 3. 后端测试调试
- **配置名称**: `后端: 运行测试`
- **功能**: 运行 pytest 测试并支持调试
- **使用方法**: 选择此配置启动，可以设置断点调试测试

### 前端调试

#### 1. Vite 开发服务器
- **配置名称**: `前端: Vite 开发服务器`
- **功能**: 启动 Vite 开发服务器（支持热重载）
- **端口**: 5173
- **使用方法**: 按 F5 或选择此配置启动

#### 2. Chrome 浏览器调试
- **配置名称**: `前端: Chrome 调试`
- **功能**: 在 Chrome 中调试前端应用
- **前提**: 需要先启动 Vite 开发服务器
- **使用方法**: 选择此配置启动

#### 3. 前端测试
- **配置名称**: `前端: 运行测试`
- **功能**: 运行前端测试
- **使用方法**: 选择此配置启动

## 任务配置

### 后端任务

1. **后端: 安装依赖**
   - 安装 Python 依赖包

2. **后端: 启动服务器**
   - 启动 FastAPI 开发服务器（后台运行）

3. **后端: 运行测试**
   - 运行 pytest 测试

### 前端任务

1. **前端: 安装依赖**
   - 安装 npm 依赖包

2. **前端: 启动开发服务器**
   - 启动 Vite 开发服务器（后台运行）

3. **前端: 构建**
   - 构建生产版本

4. **前端: 运行 Lint**
   - 运行 ESLint 检查

### 全栈任务

1. **全栈: 启动前后端**
   - 同时启动后端和前端开发服务器

## 使用方法

### 方法 1: 使用调试配置

1. 打开 VS Code
2. 按 `Cmd+Shift+D` (macOS) 或 `Ctrl+Shift+D` (Windows/Linux) 打开调试面板
3. 从下拉菜单中选择所需的配置
4. 按 `F5` 或点击绿色播放按钮启动

### 方法 2: 使用任务

1. 按 `Cmd+Shift+P` (macOS) 或 `Ctrl+Shift+P` (Windows/Linux)
2. 输入 "Tasks: Run Task"
3. 选择所需的任务

### 方法 3: 使用命令面板

1. 按 `Cmd+Shift+P` (macOS) 或 `Ctrl+Shift+P` (Windows/Linux)
2. 输入 "Debug: Start Debugging"
3. 选择配置

## 推荐的工作流程

### 开发模式

1. 启动后端服务器: `后端: FastAPI`
2. 启动前端服务器: `前端: Vite 开发服务器`
3. 在浏览器中访问 `http://localhost:5173`

### 调试模式

1. 在代码中设置断点
2. 选择相应的调试配置
3. 按 F5 启动调试
4. 使用调试工具栏控制执行流程

### 测试模式

1. 后端测试: `后端: 运行测试`
2. 前端测试: `前端: 运行测试`

## 环境要求

### 后端

- Python 3.9+
- 虚拟环境: `ConceptTree/backend/venv`
- 依赖包: 见 `ConceptTree/backend/requirements.txt`

### 前端

- Node.js 16+
- npm 或 yarn
- 依赖包: 见 `ConceptTree/frontend/package.json`

## 故障排除

### 后端无法启动

1. 检查虚拟环境是否激活
2. 运行 `后端: 安装依赖` 任务
3. 检查端口 8000 是否被占用

### 前端无法启动

1. 运行 `前端: 安装依赖` 任务
2. 检查端口 5173 是否被占用
3. 检查 Node.js 版本

### 调试器无法连接

1. 确保服务器已启动
2. 检查端口配置是否正确
3. 尝试重启 VS Code
