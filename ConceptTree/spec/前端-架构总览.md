## 路由结构

| 路由             | 组件            | 说明                           |
| ---------------- | --------------- | ------------------------------ |
| `/`              | HomePage        | 首页：输入目标 + 计划列表      |
| `/auth`          | AuthPage        | 登录/注册                      |
| `/graph/:planId` | GraphPage       | 图谱页：知识图谱画布（需登录） |
| `/my-learning`   | MyLearningPage  | 我的学习：4个Tab（需登录）     |
| `*`              | Navigate to `/` | 404重定向                      |

**路由配置** (App.jsx)：

```jsx
<BrowserRouter>
  <Routes>
    <Route path="/" element={<HomePage />} />
    <Route path="/auth" element={<AuthPage />} />
    <Route
      path="/graph/:planId"
      element={
        <ProtectedRoute>
          <GraphPage />
        </ProtectedRoute>
      }
    />
    <Route
      path="/my-learning"
      element={
        <ProtectedRoute>
          <MyLearningPage />
        </ProtectedRoute>
      }
    />
    <Route path="*" element={<Navigate to="/" replace />} />
  </Routes>
</BrowserRouter>
```

## API 策略（Hybrid：真实后端 + Mock）

当前前端通过 `/api` 访问后端，并由 Vite dev server 代理转发到后端（默认 `http://localhost:8000`，见 frontend/vite.config.js）。

API 层现状（见 frontend/src/services/api.js）：

| 模块                                          | 方式                | 说明                                             |
| --------------------------------------------- | ------------------- | ------------------------------------------------ |
| auth                                          | 真实后端            | register/login/logout；token 存 localStorage     |
| userProfile                                   | 真实后端 + fallback | get 失败时 fallback 为空画像；update 走后端      |
| plans.list                                    | 真实后端            | 列表拉取                                      |
| plans.create/update/archive/restore/delete    | 真实后端            | CRUD 操作已全量对接                           |
| graph.get/updateNodeStatus/updateNodePosition | 真实后端            | 已封装且对接完成                              |
| notes                                         | 真实后端            | 移除 LocalStorage，全量对接真实后端            |
| stats                                         | 真实后端            | 已对接 /overview 与 /distribution            |
| ai                                            | 真实后端            | parseGoal 和 graph.generate 已对接真实大模型   |

### 存储键

| Key | 说明 |

## 数据类型定义

### Plan

```typescript
interface Plan {
  id: string;
  title: string; // 计划标题
  progress: number; // 已学习节点数
  total: number; // 需学习节点数（不含skipped）
  status: "active" | "archived";
  lastAccess: string; // 友好时间显示
  createdAt: string; // ISO时间戳
}
```

### Node

```typescript
interface Node {
  id: string; // 'n' + 序号
  name: string; // 节点名称
  status: "unlearned" | "learned" | "skipped";
  x: number; // 画布X坐标
  y: number; // 画布Y坐标
  why: string; // 为什么学
  what: string[]; // 学什么
  mastery: string[]; // 掌握标准
  prompt: string; // 学习Prompt
  resources: Resource[]; // 推荐资源
  isTarget: boolean; // 是否目标节点
  domain: string; // 知识领域
}
```

### Edge

```typescript
interface Edge {
  from: string; // 起点节点ID（前端画布当前使用）
  to: string; // 终点节点ID（前端画布当前使用）
}
```

```typescript
interface BackendEdge {
  from_node: string; // 后端当前返回字段
  to_node: string;
}
```

### Note

```typescript
interface Note {
  id: string;
  planId: string;
  nodeId: string;
  content: string; // Markdown格式
  date: string; // 友好日期
  createdAt: string;
}
```
