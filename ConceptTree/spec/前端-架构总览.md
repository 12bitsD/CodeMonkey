## 路由结构

| 路由 | 组件 | 说明 |
|------|------|------|
| `/` | HomePage | 首页：输入目标 + 计划列表 |
| `/graph/:planId` | GraphPage | 图谱页：知识图谱画布 |
| `/my-learning` | MyLearningPage | 我的学习：4个Tab |
| `*` | Navigate to `/` | 404重定向 |

**路由配置** (App.jsx):
```jsx
<BrowserRouter>
  <Routes>
    <Route path="/" element={<HomePage />} />
    <Route path="/graph/:planId" element={<GraphPage />} />
    <Route path="/my-learning" element={<MyLearningPage />} />
    <Route path="*" element={<Navigate to="/" replace />} />
  </Routes>
</BrowserRouter>
```

## 全局状态 (AppContext)

### 状态结构
```javascript
{
  userProfile: {
    occupation: string,
    education: string,
    programmingLevel: '无基础' | '入门' | '熟练',
    mathLevel: '无基础' | '入门' | '熟练',

    masteredKnowledge: string[]  // 只读，学习完成后自动添加

  plans: Plan[],
  allNotes: Note[],
  isLoading: boolean

```

### 暴露的Actions
```javascript
actions: {
  setUserProfile(profile),  // 更新用户画像
  createPlan(input, graphResult),  // 创建计划

  archivePlan(id),          // 归档计划
  deletePlan(id),           // 删除计划
  addNote(planId, nodeId, content)  // 添加笔记
}
```

## Mock策略 (LocalStorage)

当前 API 层使用 LocalStorage 模拟后端，支持：
- 刷新页面数据不丢失
- URL直达（如 `/graph/p123`）

### 存储键
| Key | 说明 |
|-----|------|
| `concept_tree_profile` | 用户画像 |
| `concept_tree_plans` | 计划列表 |
| `concept_tree_notes` | 笔记数据 |
| `concept_tree_graphs` | 图谱数据 (planId -> {nodes, edges}) |

### 替换为真实API
正式开发时，只需修改 `services/api.js`：
```javascript
// 当前 Mock
const profile = storage.get(STORAGE_KEYS.PROFILE, {});

// 替换为真实API
const response = await fetch('/api/user/profile');
const profile = await response.json();
```

## 数据类型定义

### Plan
```typescript
interface Plan {
  id: string;           // 'p' + timestamp
  title: string;        // 计划标题
  progress: number;     // 已学习节点数
  total: number;        // 需学习节点数（不含skipped）
  status: 'active' | 'archived';
  lastAccess: string;   // 友好时间显示
  createdAt: string;    // ISO时间戳
}
```

### Node
```typescript
interface Node {
  id: string;           // 'n' + 序号
  name: string;         // 节点名称
  status: 'unlearned' | 'learned' | 'skipped';
  x: number;            // 画布X坐标
  y: number;            // 画布Y坐标
  why: string;          // 为什么学
  what: string[];       // 学什么
  mastery: string[];    // 掌握标准
  prompt: string;       // 学习Prompt
  resources: Resource[];// 推荐资源
  isTarget: boolean;    // 是否目标节点
  domain: string;       // 知识领域
}
```

### Edge
```typescript
interface Edge {
  from: string;  // 起点节点ID
  to: string;    // 终点节点ID
}
```

### Note
```typescript
interface Note {
  id: string;
  planId: string;
  nodeId: string;
  content: string;      // Markdown格式
  date: string;         // 友好日期
  createdAt: string;
}
```
