## 当前最关键的对齐缺口（会影响联调/验收）

| 缺口                                           | 影响面            | 当前表现                                                                     |
| ---------------------------------------------- | ----------------- | ---------------------------------------------------------------------------- |
| edges 字段映射（from/to vs from_node/to_node） | 图谱渲染/推荐逻辑 | edges 可能无法渲染或推荐错误                                                 |
| createPlan 仍为前端 Mock                       | 首页→图谱主链路   | 生成后跳转图谱可能后端无数据                                                 |
| 前端多处仍 Mock（plans/notes/stats/ai）        | 联调与验收        | 后端已具备真实端点，但前端未对接或参数口径不匹配                             |
| 错误响应格式与前端处理假设                     | 前端错误处理      | 后端已做全局错误包装；需确保前端 fetch 层始终按 `{success:false,error}` 读取 |
| Supabase 环境化测试依赖                        | 端到端验证        | 后端依赖 `DATABASE_URL`（Postgres）；无该变量时需跳过或提供开发指引          |
