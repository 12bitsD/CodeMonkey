### 已完成的架构改进

| 改进 | 说明 |
| ---- | ---- |
| AI Prompt 配置分离 | `services/llm/prompts/*.txt` → `services/llm/configs/*.json`；支持非代码调参 |
| 前端测试基础设施 | vitest（单元）+ Playwright（E2E）完整配置；6 + 4 = 10 个测试 |
| LLM 统一客户端 | `services/llm/client.py` 带重试/降级；`providers/openai_compatible.py` 兼容 Kimi |
| 全局 Toast 系统 | ToastContext + useToast hook，统一错误/成功提示 |
| user_background 全链路 | 前端 → 后端 → AI Service → Prompt，完整个性化支持 |
| clarify-goal | 后端端点 + LLM 配置 + 前端 Modal UI 完整实现 |
| recommend-next AI 推荐 | 学习历史聚合服务 + LLM 调度 + 前端降级策略（AI 优先，规则引擎兜底）|
| clarify-goal 节点上下文修复 | 传入现有节点 ID 上下文，AI 返回精确的 keep/remove diff（而非模糊名字匹配）|
| apply-changes 端点 | `POST /plans/{id}/apply-changes`：删除节点/新增 stub 节点/更新标题；前端小幅调整走此端点 |
| 后端单元测试架构 | `tests/unit/` 独立 conftest，无需 DB 环境即可运行 AI Service 单元测试 |
