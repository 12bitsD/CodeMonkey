## 功能概述（说人话）

首页有两个核心功能：**生成新计划** 和 **管理已有计划**。

### 生成新计划的完整流程

```
用户输入"我想学反向传播，我有Python基础但数学不好"
    ↓
点击"生成学习图谱"
    ↓
[调用 parse-goal] AI分析这句话
    ↓
返回：
  - 目标：理解反向传播的数学原理
  - 相关能力：Python基础
  - 新发现的背景：Python基础(✓)、数学薄弱
  - 预计节点数：7个
  - 是否需要拆分：否
    ↓
显示"确认弹窗"让用户确认
    ↓
用户点"确认生成"
    ↓
[调用 generate-graph] AI生成完整图谱（15-30秒）
    ↓
[调用 create-plan] 创建计划并保存图谱
    ↓
跳转到图谱页
```

**如果目标太大（比如用户输入"学习深度学习"）**：

```
[调用 parse-goal] 返回 shouldSplit: true
    ↓
显示"建议拆分弹窗"，给出3个更具体的子目标建议
    ↓
用户点击其中一个 → 自动填入输入框，重新走上面的流程
或者用户点"继续使用原目标" → 强制生成
```

## 接口详情

### 1. 解析学习目标（AI）

**做什么**：

1. 把用户的自由输入解析成结构化的学习目标
2. 从用户输入中提取新的背景信息（比如"我有 Python 基础"）
3. 从用户画像中筛选与目标相关的能力
4. 判断目标是否太大，太大就给出拆分建议

```
POST /api/ai/parse-goal
```

**请求**：

```json
{
  "input": "我想理解深度学习中的反向传播，我有Python基础但数学不好"
}
```

**成功（正常目标）**：

```json
{
  "success": true,
  "data": {
    "interpretation": "理解反向传播的数学原理",
    "backgroundSummary": [
      { "text": "Python入门", "source": "profile", "isStrength": true },
      { "text": "数学薄弱", "source": "input", "isStrength": false }
    ],
    "suggestedNodeCount": 7,
    "shouldSplit": false,
    "splitSuggestions": null
  }
}
```

**成功（目标太大，需要拆分）**：

```json
{
  "success": true,
  "data": {
    "interpretation": "深度学习",
    "backgroundSummary": [],
    "suggestedNodeCount": 25,
    "shouldSplit": true,
    "splitSuggestions": [
      {
        "title": "理解神经网络基础",
        "description": "从感知机到多层神经网络",
        "estimatedNodes": 6
      },
      {
        "title": "理解反向传播算法",
        "description": "深度学习训练的核心",
        "estimatedNodes": 7
      },
      {
        "title": "理解卷积神经网络",
        "description": "图像处理的基础架构",
        "estimatedNodes": 8
      }
    ]
  }
}
```

**AI 做的事情**：

1. 理解用户想学什么 → `interpretation`
2. 估算需要多少知识点 → `suggestedNodeCount`
3. 如果节点数 > 12，建议拆分 → `shouldSplit`
4. 从输入中提取背景信息（如"我有 Python 基础但数学不好"）
5. 从用户画像中找相关能力
6. 合并成 `backgroundSummary` 返回

**关于 backgroundSummary**：

- `source: "profile"` 表示从用户画像匹配到的
- `source: "input"` 表示从本次输入中新发现的
- `isStrength` 表示是优势还是弱项

**自动更新用户画像**：
规划能力：从输入中新发现的背景信息（`source: "input"`）自动写入 `user_profiles.abilities`。

当前实现：未写入数据库，仍为 mock 返回 → ❌

**前端拿到后**：

- 如果 `shouldSplit: false` → 显示"确认学习目标"弹窗
- 如果 `shouldSplit: true` → 显示"建议拆分目标"弹窗

### 2. 生成知识图谱（AI）

**做什么**：根据学习目标，AI 生成完整的知识依赖图谱。这是最核心的 AI 功能。

**注意**：这个接口会比较慢（15-30 秒），前端需要显示加载动画。

```
POST /api/ai/generate-graph
```

**请求**：

```json
{
  "input": "我想理解深度学习中的反向传播，我有Python基础但数学不好",
  "interpretation": "理解反向传播的数学原理"
}
```

**成功**：

```json
{
  "success": true,
  "data": {
    "interpretation": "理解反向传播的数学原理",
    "nodes": [
      {
        "id": "n1",
        "name": "矩阵乘法",
        "status": "unlearned",
        "x": -150,
        "y": 100,
        "why": "神经网络的前向传播本质就是 y = Wx + b，理解矩阵乘法才能理解数据如何在网络中流动。",
        "what": ["矩阵乘法的定义", "矩阵维度匹配规则", "Wx + b 的计算过程"],
        "mastery": ["手算 2x3 和 3x2 矩阵相乘", "判断两个矩阵能否相乘"],
        "prompt": "请帮我讲解矩阵乘法，重点是矩阵乘法在神经网络中的应用...",
        "resources": [
          {
            "name": "3Blue1Brown 线性代数",
            "url": "https://...",
            "reason": "可视化讲解"
          }
        ],
        "isTarget": false,
        "domain": "数学基础"
      },
      {
        "id": "n5",
        "name": "反向传播",
        "status": "unlearned",
        "x": 0,
        "y": -100,
        "why": "这是你的学习目标。",
        "what": ["梯度下降", "误差反向传递", "参数更新"],
        "mastery": ["能解释反向传播的完整流程"],
        "prompt": "...",
        "resources": [],
        "isTarget": true,
        "domain": "深度学习"
      }
    ],
    "edges": [
      { "from_node": "n1", "to_node": "n3" },
      { "from_node": "n2", "to_node": "n4" },
      { "from_node": "n3", "to_node": "n5" },
      { "from_node": "n4", "to_node": "n5" }
    ],
    "targetNodeId": "n5"
  }
}
```

**AI 做的事情**：

1. 拆解学习目标需要哪些前置知识
2. 分析知识点之间的依赖关系（谁是谁的前置）
3. 为每个节点生成：
   - `why`：为什么要学这个（和最终目标的关系）
   - `what`：具体要学什么内容
   - `mastery`：怎么判断自己学会了
   - `prompt`：去问 AI 时可以用的提示词
   - `resources`：推荐学习资源
   - `domain`：知识领域（用于统计页面）
4. 计算节点的初始布局位置（目标节点在中心）
5. **根据用户画像自动标记节点**：如果用户的 `masteredKnowledge` 里有某个知识点，自动把对应节点标记为 `skipped`

**关于自动标记**：

```
用户画像: masteredKnowledge = ["矩阵乘法", "Python基础"]
    ↓
生成图谱时发现节点"矩阵乘法"
    ↓
自动把这个节点的 status 设为 "skipped"
```

### 3. 获取计划列表

**做什么**：拿到用户所有计划，首页显示"继续学习"区域用。

```
GET /api/plans
GET /api/plans?status=active     // 只要进行中的
GET /api/plans?status=archived   // 只要归档的
```

**成功**：

```json
{
  "success": true,
  "data": [
    {
      "id": "p_abc123",
      "title": "理解反向传播算法",
      "progress": 3,
      "total": 7,
      "status": "active",
      "lastAccess": "2小时前",
      "createdAt": "2024-12-28T10:00:00Z"
    }
  ]
}
```

**字段说明**：
| 字段 | 类型 | 说明 |
|------|------|------|
| `progress` | number | 已学习的节点数（status='learned'）|
| `total` | number | 需要学的节点数（status!='skipped'）|
| `lastAccess` | string | 友好的时间显示（"刚刚"/"2 小时前"/"昨天"）|

**进度计算示例**：

- 7 个节点：3 个 learned, 2 个 unlearned, 2 个 skipped
- progress = 3, total = 5 (排除 skipped)
- 前端显示进度百分比：3/5 = 60%

### 4. 创建计划

**做什么**：把 generate-graph 返回的图谱保存成一个计划。

```
POST /api/plans
```

**请求**：

```json
{
  "title": "理解反向传播的数学原理",
  "originalInput": "我想理解深度学习中的反向传播",
  "nodes": [...],
  "edges": [
    { "from_node": "n1", "to_node": "n3" }
  ],
  "targetNodeId": "n5"
}
```

**成功**：

```json
{
  "success": true,
  "data": {
    "id": "p_abc123",
    "title": "理解反向传播的数学原理"
  }
}
```

**后端做的事**：

1. 创建 Plan 记录
2. 批量创建 Node 记录
3. 批量创建 Edge 记录

**实现偏差（重要）**：

- `POST /api/plans` 已接入鉴权与按 user_id 隔离 → ✅
- edges 的契约字段为 `{from_node,to_node}`；前端画布若使用 `{from,to}` 必须做映射 → ⚠️
- 边的主键 `edge.id` 由后端生成；API 不要求前端传 → ⚠️

### 6. 归档计划

**做什么**：把计划从首页"继续学习"移到"我的学习-归档"

```
PUT /api/plans/{plan_id}/archive
```

**成功**：

```json
{
  "success": true,
  "data": { "id": "p_abc123", "status": "archived" }
}
```

**失败**：

```json
// 404: 计划不存在
{ "success": false, "error": { "code": "PLAN_NOT_FOUND", "message": "Plan not found" } }

// 400: 已归档
{ "success": false, "error": { "code": "PLAN_ALREADY_ARCHIVED", "message": "Plan already archived" } }
```

---

### 7. 恢复计划

```
PUT /api/plans/{plan_id}/restore
```

**成功**：

```json
{
  "success": true,
  "data": { "id": "p_abc123", "status": "active" }
}
```

**失败**：

```json
// 404: 计划不存在
{ "success": false, "error": { "code": "PLAN_NOT_FOUND", "message": "Plan not found" } }

// 400: 已是激活状态
{ "success": false, "error": { "code": "PLAN_ALREADY_ACTIVE", "message": "Plan already active" } }
```
