## 功能概述（说人话）

图谱页是用户学习的主战场，有这些功能：

| 功能 | 说明 |
|------|------|
| 看图谱 | 显示知识节点和依赖关系 |
| 标记学习状态 | 把节点标记为"已学习"/"跳过"/"未学习" |
| 拖拽调整位置 | 用户可以拖动节点，保存位置 |
| 推荐下一步 | AI告诉用户接下来该学哪个节点 |
| 调整目标 | 用户想换个方向，AI帮忙调整图谱 |
| 记笔记 | 在节点上添加笔记 |

### 学习调度Agent的工作流程

```
用户打开图谱页
    ↓
[调用 recommend-next] AI分析应该学什么
    ↓
AI考虑的因素：
  - 哪些节点的前置都完成了？（可学）
  - 用户画像（背景、能力）
  - 学习历史（上次学了什么、什么时候）
  - 最短到达目标的路径
    ↓
返回推荐节点 + 推荐理由
    ↓
显示在画布底部："推荐下一步：链式法则 - 这是通往反向传播的关键路径"
```

## 接口详情

### 1. 获取图谱数据

**做什么**：拿到某个计划的完整图谱，包括所有节点和边。

```
GET /api/plans/:planId/graph
```

**成功**：
```json
{
  "success": true,
  "data": {
    "planId": "p_abc123",
    "title": "理解反向传播的数学原理",
    "nodes": [
      {
        "id": "n1",
        "name": "矩阵乘法",
        "status": "learned",
        "x": -150,
        "y": 100,
        "why": "神经网络的前向传播本质就是 y = Wx + b...",
        "what": ["矩阵乘法的定义", "矩阵维度匹配规则"],
        "mastery": ["手算 2x3 和 3x2 矩阵相乘"],
        "prompt": "请帮我讲解矩阵乘法...",
        "resources": [{ "name": "3Blue1Brown", "url": "...", "reason": "..." }],
        "isTarget": false
      }
    ],
    "edges": [
      { "from": "n1", "to": "n3" }
    ]
  }
}
```

**副作用**：更新计划的 `lastAccessAt`（用于首页显示"上次访问"）

---

### 2. 更新节点状态

**做什么**：用户点"标记已学习"/"标记为不需要"/"撤销"时调用。

```
PUT /api/plans/:planId/nodes/:nodeId/status
```

**请求**：
```json
{
  "status": "learned"
}
```

status 可选值：
- `unlearned` - 未学习（撤销时用）
- `learned` - 已学习
- `skipped` - 跳过/不需要

**成功**：
```json
{
  "success": true,
  "data": {
    "nodeId": "n1",
    "status": "learned",
    "plan": {
      "progress": 4,
      "total": 7
    }
  }
}
```

**后端做的事**：
1. 更新节点状态
2. 重新计算计划进度：
   - `progress` = status='learned' 的节点数
   - `total` = status!='skipped' 的节点数
3. **记录学习历史**：往 `learning_sessions` 表插入一条记录
4. **如果 status=learned**：把节点名字添加到用户画像的 `masteredKnowledge`

```
用户标记"矩阵乘法"为已学习
    ↓
1. UPDATE nodes SET status='learned'
2. INSERT INTO learning_sessions (action='learned', node_name='矩阵乘法')
3. UPDATE user_profiles.mastered_knowledge 追加 "矩阵乘法"
```

这样下次用户学新东西时，如果图谱里有"矩阵乘法"，会自动标记为"不需要"。

---

### 3. 保存节点位置

**做什么**：用户拖动节点后保存坐标。

```
PUT /api/plans/:planId/nodes/:nodeId/position
```

**请求**：
```json
{
  "x": 120.5,
  "y": -80.3
}
```

**注意**：这个接口会被频繁调用（拖拽过程中），前端需要做**节流**（throttle 200ms）。

**优化方案**：如果觉得太频繁，可以改成"松开鼠标时才保存"或"离开页面时批量保存"。

### 4. 推荐下一学习节点（学习调度Agent）

**做什么**：AI分析当前状态，推荐用户下一步应该学什么。

这是PRD里定义的"学习调度Agent"。

```
POST /api/ai/recommend-next
```

**请求**：
```json
{
  "planId": "p_abc123"
}
```

后端自己会去查：图谱数据、用户画像、学习历史。

**成功（有推荐）**：
```json
{
  "success": true,
  "data": {
    "recommendedNodeId": "n2",
    "nodeName": "链式法则",
    "reason": "链式法则是通往反向传播的关键路径，且你已完成前置的矩阵乘法"
  }
}
```

**成功（全部学完）**：
```json
{
  "success": true,
  "data": {
    "recommendedNodeId": null,
    "reason": "恭喜！你已完成所有知识点的学习",
    "isComplete": true
  }
}
```

**AI考虑的因素**：

根据PRD定义，AI的输入包括：

```json
{
  "graph": {
    "nodes": [...],
    "edges": [...],
    "target_node_id": "5"
  },
  "user_profile": {
    "occupation": "大三计算机学生",
    "programming_level": "入门",
    "math_level": "入门",
    "abilities": ["Python 会基础语法", "线性代数 只记得矩阵乘法"]
  },
  "learning_history": {
    "last_node": "矩阵乘法",
    "last_session": "2024-12-28 15:30",
    "learned_nodes": ["n1", "n3"],
    "skipped_nodes": ["n2"]
  },
  "learning_goal": "理解反向传播的数学原理"
}
```

**推荐逻辑**：
1. 先筛选"可学"的节点（前置都完成了）
2. 从可学节点中，选择最接近目标的
3. 考虑用户背景，选择难度合适的
4. 生成人话的推荐理由

### 5. 澄清/调整目标（AI）

**做什么**：用户想调整学习方向时，AI分析怎么改图谱。

**场景**：用户在图谱页点"修改目标"，输入"我更想聚焦代码实现，数学推导可以简化"

```
POST /api/ai/clarify-goal
```

**请求**：
```json
{
  "planId": "p_abc123",
  "clarification": "我更想聚焦代码实现，数学推导可以简化一些"
}
```

**成功（正常调整）**：
```json
{
  "success": true,
  "data": {
    "newGoal": "反向传播的代码实现",
    "changes": {
      "keep": [
        { "nodeId": "n1", "name": "矩阵乘法", "currentStatus": "learned" },
        { "nodeId": "n3", "name": "前向传播", "currentStatus": "learned" }
      ],
      "add": [
        { "tempId": "new_1", "name": "Python实现基础", "why": "..." },
        { "tempId": "new_2", "name": "NumPy矩阵操作", "why": "..." }
      ],
      "remove": [
        { "nodeId": "n2", "name": "泰勒展开" },
        { "nodeId": "n6", "name": "极限定义" }
      ]
    },
    "shouldCreateNew": false,
    "warning": null
  }
}
```

**成功（调整幅度太大，建议新建）**：
```json
{
  "success": true,
  "data": {
    "newGoal": "机器学习基础",
    "changes": { ... },
    "shouldCreateNew": true,
    "warning": "调整幅度较大（保留1个，新增6个，移除5个），建议新建计划"
  }
}
```

**成功（用户输入不清晰）**：
```json
{
  "success": true,
  "data": {
    "needMoreInfo": true,
    "questions": [
      "想增加哪方面内容？",
      "想减少哪方面内容？"
    ]
  }
}
```

**前端流程**：
1. 显示变更预览（保留/新增/移除）
2. 如果 `shouldCreateNew: true`，显示警告并提供"新建计划"按钮
3. 如果 `needMoreInfo: true`，显示追问弹窗
4. 用户确认后，调用 `POST /api/plans/:planId/apply-changes` 执行变更

---

### 6. 应用目标调整

**做什么**：用户确认调整方案后，真正执行图谱变更。

```
POST /api/plans/:planId/apply-changes
```

**请求**：
```json
{
  "newGoal": "反向传播的代码实现",
  "keep": ["n1", "n3", "n4"],
  "add": [
    { 
      "name": "Python实现基础", 
      "why": "需要了解Python基础才能实现代码",
      "what": ["Python语法", "NumPy基础"],
      "mastery": ["能写简单的Python程序"],
      "prompt": "请帮我讲解Python基础...",
      "domain": "编程"
    }
  ],
  "remove": ["n2", "n6"],
  "newEdges": [
    { "from": "new_0", "to": "n4" }
  ]
}
```

**成功**：
```json
{
  "success": true,
  "data": {
    "planId": "p_abc123",
    "title": "反向传播的代码实现",
    "nodesAdded": 2,
    "nodesRemoved": 2,
    "message": "图谱已更新"
  }
}
```

**后端做的事**：
1. 更新计划标题
2. 删除 `remove` 中的节点（级联删除相关边和笔记）
3. 创建 `add` 中的新节点（分配新ID，如 `n_new_1`）
4. 创建 `newEdges` 中的新边
5. 重新计算进度

**错误情况**：
- 404 `PLAN_NOT_FOUND` - 计划不存在
- 400 `INVALID_NODE_IDS` - keep/remove 中包含不存在的节点ID

---

### 7. 批量保存节点位置

**做什么**：重置布局后一次性保存所有节点位置。

```
PUT /api/plans/:planId/nodes/positions
```

**请求**：
```json
{
  "positions": [
    { "nodeId": "n1", "x": 100, "y": 200 },
    { "nodeId": "n2", "x": -50, "y": 100 },
    { "nodeId": "n3", "x": 0, "y": 0 }
  ]
}
```

**成功**：
```json
{
  "success": true,
  "data": {
    "updated": 3
  }
}
```

**使用场景**：
- 用户点击"重置布局"后，前端重新计算所有节点位置，然后一次性保存
- 相比单个保存，减少网络请求次数

## 数据库设计

```sql
-- 节点表
CREATE TABLE nodes (
  id VARCHAR(36) PRIMARY KEY,
  plan_id VARCHAR(36) REFERENCES plans(id) ON DELETE CASCADE,
  name VARCHAR(200) NOT NULL,
  status ENUM('unlearned', 'learned', 'skipped') DEFAULT 'unlearned',
  x FLOAT DEFAULT 0,
  y FLOAT DEFAULT 0,
  why TEXT,
  what JSON DEFAULT '[]',
  mastery JSON DEFAULT '[]',
  prompt TEXT,
  resources JSON DEFAULT '[]',
  domain VARCHAR(50),
  is_target BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  
  INDEX idx_plan (plan_id)
);

-- 边表
CREATE TABLE edges (
  id VARCHAR(36) PRIMARY KEY,
  plan_id VARCHAR(36) REFERENCES plans(id) ON DELETE CASCADE,
  from_node_id VARCHAR(36) REFERENCES nodes(id) ON DELETE CASCADE,
  to_node_id VARCHAR(36) REFERENCES nodes(id) ON DELETE CASCADE,
  
  UNIQUE KEY uk_edge (plan_id, from_node_id, to_node_id)
);

-- 学习历史表（用于推荐算法）
-- 每次用户标记节点状态时记录一条
CREATE TABLE learning_sessions (
  id VARCHAR(36) PRIMARY KEY,
  user_id VARCHAR(36) REFERENCES users(id),
  plan_id VARCHAR(36) REFERENCES plans(id),
  node_id VARCHAR(36) REFERENCES nodes(id),
  node_name VARCHAR(200),                              -- 冗余存储，方便查询
  action ENUM('learned', 'skipped', 'reverted'),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  
  INDEX idx_user_recent (user_id, created_at DESC),
  INDEX idx_plan (plan_id)
);

-- 用途：
-- 1. recommend-next 需要知道用户上次学了什么、什么时候学的
-- 2. 统计页面需要知道本周完成了多少节点
-- 3. 可以分析用户的学习模式
```
