## 功能概述

图谱页是用户学习的主战场，包含：
1. **知识图谱画布** - 可缩放、拖拽的节点图
2. **节点详情侧边栏** - 查看节点内容、标记状态、记笔记
3. **推荐浮层** - AI推荐下一步学习内容
4. **缩放控制** - 放大/缩小/重置视图

## 节点渲染

### 状态样式

| 状态 | 样式 |
|------|------|
| `unlearned` | 白底 + 灰色边框 + ○图标 |
| `learned` | 黑底白字 + ✓图标 |
| `skipped` | 白底 + 删除线 + 半透明 |
| `isTarget` | 青色边框 + 🎯图标 |

### 缩放级别

| scale | 显示 |
|-------|------|
| < 0.6 | 只显示小圆点 |
| ≥ 0.6 | 显示图标 + 名称 |

### 节点数据结构

```javascript
{
  id: 'n1',
  name: '矩阵乘法',
  status: 'unlearned',  // 'unlearned' | 'learned' | 'skipped'
  x: -150,
  y: 100,
  why: '神经网络的前向传播本质就是 y = Wx + b...',
  what: ['矩阵乘法的定义', '维度匹配规则'],
  mastery: ['手算2x3矩阵相乘'],
  prompt: '请帮我讲解矩阵乘法...',
  resources: [{ name, url, reason }],
  isTarget: false,
  domain: '数学基础'
}
```

## 边渲染

```javascript
{edges.map((edge, i) => {
  const from = nodes.find(n => n.id === edge.from);
  const to = nodes.find(n => n.id === edge.to);
  
  const isTraversed = from.status === 'learned';
  
  return (
    <line 
      x1={from.x} y1={from.y} 
      x2={to.x} y2={to.y}
      stroke={isTraversed ? "#0D9488" : "#E4E4E7"}
      strokeDasharray={from.status === 'skipped' ? '4,4' : '0'}
    />
  );
})}
```

| 状态 | 样式 |
|------|------|
| 默认 | 灰色实线 |
| 起点已学习 | 青色实线 + 中点圆点 |
| 起点已跳过 | 灰色虚线 |

## 推荐浮层

### 显示条件
- `selectedNodeId` 为空（未选中节点）
- `recommendedNode` 存在

### 推荐逻辑 (useGraphInteraction)

```javascript
const recommendedNode = useMemo(() => {
  return nodes.find(n => 
    n.status === 'unlearned' && 
    edges
      .filter(e => e.to === n.id)
      .every(e => nodes.find(fn => fn.id === e.from)?.status !== 'unlearned')
  );
}, [nodes, edges]);
```

即：找到第一个"前置都已完成"的未学习节点。

### 加载图谱

```javascript
useEffect(() => {
  const loadGraph = async () => {
    const data = await graphApi.get(planId);
    setNodes(data.nodes);
  // 注意：后端当前返回 edges 为 {from_node,to_node}，但前端画布使用 {from,to}
  setEdges((data.edges || []).map(e => ({ from: e.from_node, to: e.to_node })));

  loadGraph();
```
