# 后端通用规范

## 接口规范

### 基础URL
```
开发环境: http://localhost:3000/api
生产环境: https://api.pathfinder.com/api
```

### 认证方式
所有需要认证的接口，请求头需要携带：
```
Authorization: Bearer <jwt_token>
```

Token有效期：7天（604800秒）

## 错误码定义

### 通用错误 (4xx)
| HTTP状态码 | 错误码 | 说明 |
|------------|--------|------|
| 400 | `BAD_REQUEST` | 请求参数错误 |
| 401 | `UNAUTHORIZED` | 未登录或token无效 |
| 403 | `FORBIDDEN` | 无权限访问 |
| 404 | `NOT_FOUND` | 资源不存在 |
| 409 | `CONFLICT` | 资源冲突 |
| 429 | `TOO_MANY_REQUESTS` | 请求过于频繁 |

### 认证错误
| 错误码 | 说明 |
|--------|------|
| `INVALID_EMAIL` | 邮箱格式不正确 |
| `WEAK_PASSWORD` | 密码强度不足（<6位） |
| `EMAIL_EXISTS` | 邮箱已被注册 |
| `INVALID_CREDENTIALS` | 邮箱或密码错误 |
| `TOKEN_EXPIRED` | Token已过期 |

### 业务错误
| 错误码 | 说明 |
|--------|------|
| `PLAN_NOT_FOUND` | 计划不存在 |
| `NODE_NOT_FOUND` | 节点不存在 |
| `NOTE_NOT_FOUND` | 笔记不存在 |
| `PLAN_NOT_ARCHIVED` | 计划未处于归档状态 |
| `CONTENT_REQUIRED` | 内容不能为空 |

### AI服务错误
| 错误码 | 说明 |
|--------|------|
| `AI_SERVICE_ERROR` | AI服务调用失败 |
| `AI_TIMEOUT` | AI服务超时 |
| `GOAL_TOO_VAGUE` | 学习目标过于模糊 |

## 数据库设计汇总

### ER图概览
```
users (1) ──── (1) user_profiles
  │
  └── (1) ──── (n) plans
                    │
                    ├── (1) ──── (n) nodes
                    │                 │
                    │                 └── (n) ──── (1) notes
                    │
                    └── (1) ──── (n) edges
                    
users (1) ──── (n) learning_sessions
```

### 完整建表语句

```sql
-- 1. 用户表
CREATE TABLE users (
  id VARCHAR(36) PRIMARY KEY,
  email VARCHAR(255) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  last_login_at TIMESTAMP
);

-- 2. 用户画像表
CREATE TABLE user_profiles (
  id VARCHAR(36) PRIMARY KEY,
  user_id VARCHAR(36) UNIQUE NOT NULL,
  occupation VARCHAR(100),
  education VARCHAR(100),
  programming_level ENUM('无基础', '入门', '熟练') DEFAULT '入门',
  math_level ENUM('无基础', '入门', '熟练') DEFAULT '入门',
  abilities JSON DEFAULT '[]',
  mastered_knowledge JSON DEFAULT '[]',
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

-- 3. 学习计划表
CREATE TABLE plans (
  id VARCHAR(36) PRIMARY KEY,
  user_id VARCHAR(36) NOT NULL,
  title VARCHAR(200) NOT NULL,
  original_input TEXT,
  target_node_id VARCHAR(36),
  status ENUM('active', 'archived') DEFAULT 'active',
  last_access_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
  INDEX idx_user_status (user_id, status),
  INDEX idx_user_access (user_id, last_access_at DESC)
);

-- 4. 知识节点表
CREATE TABLE nodes (
  id VARCHAR(36) PRIMARY KEY,
  plan_id VARCHAR(36) NOT NULL,
  name VARCHAR(200) NOT NULL,
  status ENUM('unlearned', 'learned', 'skipped') DEFAULT 'unlearned',
  x FLOAT DEFAULT 0,
  y FLOAT DEFAULT 0,
  why TEXT,
  what JSON DEFAULT '[]',
  mastery JSON DEFAULT '[]',
  prompt TEXT,
  resources JSON DEFAULT '[]',
  domain VARCHAR(50),
  is_target BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  FOREIGN KEY (plan_id) REFERENCES plans(id) ON DELETE CASCADE,
  INDEX idx_plan (plan_id),
  INDEX idx_plan_status (plan_id, status)
);

-- 5. 依赖边表
CREATE TABLE edges (
  id VARCHAR(36) PRIMARY KEY,
  plan_id VARCHAR(36) NOT NULL,
  from_node_id VARCHAR(36) NOT NULL,
  to_node_id VARCHAR(36) NOT NULL,
  
  FOREIGN KEY (plan_id) REFERENCES plans(id) ON DELETE CASCADE,
  FOREIGN KEY (from_node_id) REFERENCES nodes(id) ON DELETE CASCADE,
  FOREIGN KEY (to_node_id) REFERENCES nodes(id) ON DELETE CASCADE,
  UNIQUE KEY uk_edge (plan_id, from_node_id, to_node_id)
);

-- 6. 笔记表
CREATE TABLE notes (
  id VARCHAR(36) PRIMARY KEY,
  plan_id VARCHAR(36) NOT NULL,
  node_id VARCHAR(36) NOT NULL,
  user_id VARCHAR(36) NOT NULL,
  content TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  FOREIGN KEY (plan_id) REFERENCES plans(id) ON DELETE CASCADE,
  FOREIGN KEY (node_id) REFERENCES nodes(id) ON DELETE CASCADE,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
  INDEX idx_user (user_id),
  INDEX idx_plan (plan_id),
  INDEX idx_node (node_id),
  FULLTEXT INDEX ft_content (content)
);

-- 7. 学习历史表
CREATE TABLE learning_sessions (
  id VARCHAR(36) PRIMARY KEY,
  user_id VARCHAR(36) NOT NULL,
  plan_id VARCHAR(36) NOT NULL,
  node_id VARCHAR(36) NOT NULL,
  node_name VARCHAR(200),
  action ENUM('learned', 'skipped', 'reverted') NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
  FOREIGN KEY (plan_id) REFERENCES plans(id) ON DELETE CASCADE,
  FOREIGN KEY (node_id) REFERENCES nodes(id) ON DELETE CASCADE,
  INDEX idx_user_recent (user_id, created_at DESC),
  INDEX idx_plan (plan_id)
);
```

## ID生成规则

| 实体 | 前缀 | 示例 |
|------|------|------|
| 用户 | `u_` | `u_abc123` |
| 画像 | `profile_` | `profile_abc123` |
| 计划 | `p_` 或 `p` | `p_abc123` 或 `p1703990400000` |
| 节点 | `n` | `n1`, `n2` |
| 边 | `e_` | `e_abc123` |
| 笔记 | `note_` 或 `n` | `note_abc123` 或 `n1703990400000` |
| 学习记录 | `ls_` | `ls_abc123` |

推荐使用 UUID v4 或 时间戳+随机数 生成。

---

## 时间格式

- 存储：ISO 8601 格式 `2024-12-30T12:00:00Z`
- 友好显示：由后端计算返回
  - `刚刚` - 1分钟内
  - `5分钟前` - 1小时内
  - `2小时前` - 24小时内
  - `昨天` - 1-2天
  - `12/28` - 超过2天
