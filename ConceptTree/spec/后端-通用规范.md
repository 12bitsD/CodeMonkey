## 接口规范

### 基础URL

```
后端直连（FastAPI）: http://localhost:8000/api
前端开发（Vite Proxy）: http://localhost:3000/api  （转发到 http://localhost:8000）
生产环境: TBD
```

### 认证方式

所有需要认证的接口，请求头需要携带：

```
Authorization: Bearer <jwt_token>
```

Token有效期：7天（604800秒）

### 鉴权现状（实现偏差）

- 契约（推荐）：除注册/登录/健康检查外，其余业务接口均应要求 Bearer token，并按 user_id 做数据隔离。
- 当前实现（代码现状）：仅 `POST /api/auth/logout`、`GET/PUT /api/user/profile` 校验 token；其余模块暂未接入鉴权/多用户隔离，部分逻辑使用固定 `user_default`。

```json
{
```

```json
  "error": {
    "code": "ERROR_CODE",
    "message": "人类可读的错误描述"
```

### 错误响应的实现偏差（需尽快统一）

- 推荐：所有错误都应直接返回如上结构（或由框架统一包装）。
- 当前实现：部分接口会抛出 `HTTPException(detail={code,message})` 或 `HTTPException(detail={success:false,error:{...}})`，导致前端/调用方需要做兼容处理。

## 错误码定义

### 通用错误 (4xx)

| HTTP状态码 | 错误码              | 说明              |
| ---------- | ------------------- | ----------------- |
| 400        | `BAD_REQUEST`       | 请求参数错误      |
| 401        | `UNAUTHORIZED`      | 未登录或token无效 |
| 403        | `FORBIDDEN`         | 无权限访问        |
| 404        | `NOT_FOUND`         | 资源不存在        |
| 409        | `CONFLICT`          | 资源冲突          |
| 429        | `TOO_MANY_REQUESTS` | 请求过于频繁      |

### 认证错误

| 错误码                | 说明                 |
| --------------------- | -------------------- |
| `INVALID_EMAIL`       | 邮箱格式不正确       |
| `WEAK_PASSWORD`       | 密码强度不足（<6位） |
| `EMAIL_EXISTS`        | 邮箱已被注册         |
| `INVALID_CREDENTIALS` | 邮箱或密码错误       |
| `TOKEN_EXPIRED`       | Token已过期          |

### 业务错误

| 错误码              | 说明               |
| ------------------- | ------------------ |
| `PLAN_NOT_FOUND`    | 计划不存在         |
| `NODE_NOT_FOUND`    | 节点不存在         |
| `NOTE_NOT_FOUND`    | 笔记不存在         |
| `PLAN_NOT_ARCHIVED` | 计划未处于归档状态 |
| `CONTENT_REQUIRED`  | 内容不能为空       |

### AI服务错误

| 错误码             | 说明             |
| ------------------ | ---------------- |
| `AI_SERVICE_ERROR` | AI服务调用失败   |
| `AI_TIMEOUT`       | AI服务超时       |
| `GOAL_TOO_VAGUE`   | 学习目标过于模糊 |

## 数据库设计汇总

### ER图概览

```
users (1) ──── (1) user_profiles
  │
  └── (1) ──── (n) plans
                    │
                    ├── (1) ──── (n) nodes
                    │                 │
                    │                 └── (n) ──── (1) notes
                    │
                    └── (1) ──── (n) edges

users (1) ──── (n) learning_sessions
```

### 完整建表语句

```sql
-- 当前实现数据库：SQLite3（见 backend/database.py）
-- 说明：
-- - JSON/数组字段以 TEXT 存储（通常为 JSON 字符串）
-- - 不使用 ENUM / ON UPDATE / FULLTEXT INDEX 等 MySQL 专属语法

CREATE TABLE IF NOT EXISTS users (
  id TEXT PRIMARY KEY,
  email TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS user_profiles (
  id TEXT PRIMARY KEY,
  user_id TEXT UNIQUE NOT NULL,
  occupation TEXT,
  education TEXT,
  programming_level TEXT DEFAULT '入门',
  math_level TEXT DEFAULT '入门',
  abilities TEXT DEFAULT '[]',
  mastered_knowledge TEXT DEFAULT '[]',
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE TABLE IF NOT EXISTS plans (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  title TEXT NOT NULL,
  original_input TEXT,
  target_node_id TEXT,
  progress INTEGER DEFAULT 0,
  total INTEGER DEFAULT 0,
  status TEXT DEFAULT 'active',
  last_access_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id)
);

CREATE TABLE IF NOT EXISTS nodes (
  id TEXT PRIMARY KEY,
  plan_id TEXT NOT NULL,
  name TEXT NOT NULL,
  status TEXT DEFAULT 'unlearned',
  x REAL DEFAULT 0,
  y REAL DEFAULT 0,
  why TEXT,
  what TEXT,
  mastery TEXT,
  prompt TEXT,
  resources TEXT,
  is_target INTEGER DEFAULT 0,
  domain TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (plan_id) REFERENCES plans(id) ON DELETE CASCADE
);

CREATE TABLE IF NOT EXISTS edges (
  id TEXT PRIMARY KEY,
  plan_id TEXT NOT NULL,
  from_node_id TEXT NOT NULL,
  to_node_id TEXT NOT NULL,
  FOREIGN KEY (plan_id) REFERENCES plans(id) ON DELETE CASCADE,
  FOREIGN KEY (from_node_id) REFERENCES nodes(id) ON DELETE CASCADE,
  FOREIGN KEY (to_node_id) REFERENCES nodes(id) ON DELETE CASCADE,
  UNIQUE(plan_id, from_node_id, to_node_id)
);

CREATE TABLE IF NOT EXISTS learning_sessions (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  plan_id TEXT NOT NULL,
  node_id TEXT NOT NULL,
  node_name TEXT,
  action TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
  FOREIGN KEY (plan_id) REFERENCES plans(id) ON DELETE CASCADE,
  FOREIGN KEY (node_id) REFERENCES nodes(id) ON DELETE CASCADE
);

CREATE TABLE IF NOT EXISTS notes (
  id TEXT PRIMARY KEY,
  plan_id TEXT NOT NULL,
  node_id TEXT NOT NULL,
  user_id TEXT NOT NULL,
  content TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (plan_id) REFERENCES plans(id) ON DELETE CASCADE,
  FOREIGN KEY (node_id) REFERENCES nodes(id) ON DELETE CASCADE,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
```

## 时间格式

- 存储：ISO 8601 格式 `2024-12-30T12:00:00Z`
- 友好显示：由后端计算返回
  - `刚刚` - 1分钟内
  - `5分钟前` - 1小时内
  - `2小时前` - 24小时内
  - `昨天` - 1-2天
  - `12/28` - 超过2天
