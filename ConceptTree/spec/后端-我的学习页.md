## 功能概述（说人话）

"我的学习"页面有4个Tab：

| Tab      | 功能                                        |
| -------- | ------------------------------------------- |
| 归档计划 | 查看已归档的计划，可以恢复或删除            |
| 我的画像 | 查看/编辑个人背景信息（见"认证与用户"文档） |
| 全部笔记 | 查看所有计划的所有笔记，支持搜索            |
| 学习统计 | 看看自己学了多少东西，知识领域分布          |

## Tab: 归档计划

### 1. 恢复计划

**做什么**：把归档的计划恢复到首页"继续学习"区域。

```
PUT /api/plans/{planId}/restore
```

**成功**：

```json
{
  "success": true,
  "data": { "id": "p_abc123", "status": "active" }
}
```

---

### 2. 删除计划

**做什么**：彻底删除计划。这是危险操作，会连带删除所有节点、边、笔记。

```
DELETE /api/plans/{planId}
```

**成功**：

```json
{
  "success": true,
  "message": "计划已删除"
}
```

**后端做的事**：

1. 删除 Plan 记录
2. 级联删除所有 Node（因为有 ON DELETE CASCADE）
3. 级联删除所有 Edge
4. 级联删除所有 Note

**前端注意**：需要二次确认弹窗。

## Tab: 全部笔记

### 3. 获取笔记列表

**做什么**：拿到用户所有笔记，支持按计划筛选、关键词搜索。

```
GET /api/notes
GET /api/notes?planId=p_abc123           // 只看某个计划的笔记
GET /api/notes?search=矩阵               // 搜索笔记内容
GET /api/notes?planId=p_abc123&search=矩阵
```

**成功**：

```json
{
  "success": true,
  "data": {
    "notes": [
      {
        "id": "note_abc123",
        "planId": "p_abc123",
        "planTitle": "理解反向传播",
        "nodeId": "n1",
        "nodeName": "矩阵乘法",
        "content": "关键是**维度匹配**：左矩阵的列数等于右矩阵的行数",
        "date": "12/28",
        "createdAt": "2024-12-28T15:30:00Z"
      }
    ],
    "total": 14
  }
}
```

**字段说明**：

- `planTitle`、`nodeName`：JOIN 查出来的，方便前端显示
- `date`：友好的日期显示（"12/28"）
- `content`：支持 Markdown 格式

## Tab: 学习统计

### 7. 获取学习统计

**做什么**：拿到用户的学习统计数据，显示在"学习统计"Tab。

```
GET /api/stats/overview
```

**成功**：

```json
{
  "success": true,
  "data": {
    "summary": {
      "completedPlans": 3,
      "activePlans": 2,
      "masteredKnowledge": 27,
      "totalNotes": 14
    },
    "thisWeek": {
      "completedNodes": 5,
      "newNotes": 3
    }
  }
}
```

**字段说明**：
| 字段 | 怎么算 |
|------|--------|
| completedPlans | 归档计划中，progress=total 的数量 |
| activePlans | status=active 的计划数量 |
| masteredKnowledge | user_profiles.mastered_knowledge 的长度 |
| totalNotes | 用户所有笔记数量 |
| thisWeek.completedNodes | 本周标记为 learned 的节点数 |
| thisWeek.newNotes | 本周新建的笔记数 |

### 8. 获取知识领域分布

**做什么**：统计用户已掌握知识的领域分布，显示柱状图。

```
GET /api/stats/distribution
```

**成功**：

```json
{
  "success": true,
  "data": {
    "distribution": [
      { "domain": "深度学习", "count": 12, "percentage": 44 },
      { "domain": "数学基础", "count": 8, "percentage": 30 },
      { "domain": "编程", "count": 5, "percentage": 19 },
      { "domain": "其他", "count": 2, "percentage": 7 }
    ],
    "total": 27
  }
}
```

**怎么实现**：

在 `generate-graph` 时，AI为每个节点打上 `domain` 标签（如"深度学习"/"数学基础"/"编程"）。

统计时：

```sql
SELECT n.domain, COUNT(*) as count
FROM nodes n
JOIN plans p ON n.plan_id = p.id
WHERE p.user_id = ? AND n.status = 'learned'
GROUP BY n.domain
ORDER BY count DESC
```

## 数据库设计

```sql
-- 笔记表
CREATE TABLE notes (
  id VARCHAR(36) PRIMARY KEY,
  plan_id VARCHAR(36) REFERENCES plans(id) ON DELETE CASCADE,
  node_id VARCHAR(36) REFERENCES nodes(id) ON DELETE CASCADE,
  user_id VARCHAR(36) REFERENCES users(id),
  content TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

  INDEX idx_user (user_id),
  INDEX idx_plan (plan_id),
  INDEX idx_node (node_id),
  FULLTEXT INDEX ft_content (content)  -- 用于搜索
);
```
